Como funciona

Três passos, do perfil inteiro ao ZIP.

  1. Cole o link do perfil

    Formato https://www.tiktok.com/@usuario.

  2. Escolha os vídeos

    O grid mostra até 20 vídeos. Marque os que quiser.

  3. Baixe em ZIP

    Clique em "Baixar selecionados". O ZIP chega automaticamente.

Perguntas frequentes

Funciona com contas privadas?

Não. Só perfis e vídeos públicos podem ser processados.

Quantos vídeos posso carregar?

Até 20 por vez (padrão). O limite protege o servidor e o TikTok de consultas em massa.

Preciso instalar algo?

Python 3.8+, pip install flask yt-dlp. O ffmpeg é opcional, só para MP3.

Meus vídeos ficam salvos no servidor?

Não. Arquivos temporários são apagados automaticamente em poucos minutos.
